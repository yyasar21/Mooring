# Phase A3 — home lab integration (lab is read-only for agents)

1. vSphere provider: vcenter.homelab.xyz inventory import (datacenter/cluster/host/VM) into a synced folder, WebMKS console, power state; scheduled refresh.
2. Kubernetes provider: contexts from kubeconfig (OKD, RKE2, TKG), namespaces/pods, `exec` shells, port-forward, logs; never mutates.
3. OpenBao credential source: "KV v2 path" credentials resolved at connect time with a short-lived token (OIDC/LDAP via AD); nothing cached on disk.
4. App sign-in with Active Directory (LDAPS to xdc01) as optional second layer; FIDO2 hmac-secret as vault second factor.
5. Vault sync: encrypted blob to Garage S3 (s3.homelab.xyz) with conflict detection; client-side encryption only.
6. Inspector network tools: ping, TCP port check, traceroute, WireGuard tunnel status.

Tests: `lab`-tagged integration tests (NEXUS_LAB=1); E2E import of the real vCenter inventory.
Security focus: token lifetimes, LDAP injection, S3 blob integrity (AEAD + version counters).
