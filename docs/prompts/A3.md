# Phase A3 — infrastructure integration (any real infrastructure is read-only for agents)

1. vSphere provider: vCenter (`<lab-host>`) inventory import (datacenter/cluster/host/VM) into a synced folder, WebMKS console, power state; scheduled refresh.
2. Kubernetes provider: contexts from kubeconfig (any conformant distribution), namespaces/pods, `exec` shells, port-forward, logs; never mutates.
3. OpenBao credential source: "KV v2 path" credentials resolved at connect time with a short-lived token (OIDC/LDAP via AD); nothing cached on disk.
4. App sign-in with Active Directory (LDAPS to a domain controller) as optional second layer; FIDO2 hmac-secret as vault second factor.
5. Vault sync: encrypted blob to an S3-compatible store with conflict detection; client-side encryption only.
6. Inspector network tools: ping, TCP port check, traceroute, WireGuard tunnel status.

Tests: `#[ignore]`d lab integration tests (`MOORING_LAB_*`, read-only); E2E import of a vCenter inventory.
Security focus: token lifetimes, LDAP injection, S3 blob integrity (AEAD + version counters).
