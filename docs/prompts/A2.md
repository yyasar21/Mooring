# Phase A2 — RDP + VNC + web sessions

1. RDP via IronRDP: NLA/CredSSP, TLS with an optional private CA + system roots, certificate TOFU with explicit approval, dynamic resolution on resize, clipboard text both ways, keyboard layouts (TR-Q and US), audio off by default, RemoteFX/bitmap codecs; frames to a canvas via a zero-copy path; target 30 fps at 1080p on a MacBook.
2. VNC: RFB 3.8, Tight/ZRLE/Raw, VeNCrypt TLS, password + none auth, view-only toggle.
3. Web sessions: an isolated Tauri WebView per connection with its own capability set and partitioned storage; optional private CA trusted; for infrastructure web UIs (hypervisor consoles, dashboards, firewalls, GitOps tools).
4. Shared session features: reconnect with backoff, metadata-only session recording to the audit log, screenshot to clipboard, fullscreen, multi-window.
5. Tests: IronRDP against `<lab-host>` RDP servers (read-only test account via the local `.env`); VNC against TigerVNC in CI; fuzz RDP PDU parsing nightly; Playwright E2E per session type.

Security focus: parser hardening, WebView isolation, clipboard leakage, certificate handling.
