## Left open

- **No streaming / cancel** (N1 left it open): the card shows "Running…" until the promise resolves (≤ 30 s ping, ≤ 60 s traceroute). When rust-core adds `net://progress` + `net_cancel`, `useNet.run` is the one place to stream lines into and a Cancel button goes on the tool row.
- **`net_tools` is vault-gated**, so the card cannot grey buttons on the lock screen; it is only rendered in the unlocked inspector, so nothing is lost. If N1's "move to `NOT_GATED`" is taken, nothing in the UI changes.
- **Restart UX**: `update_install` resolves only on failure (success restarts the process, on Windows the plugin exits itself). The card shows "Downloading and verifying the update… Mooring restarts when it is installed." as the status while the promise is pending; there is no progress because the plugin exposes none through U0.
- `update_settings_get` is read on each card mount and after a successful check; it is not polled (not in `ipc-passive.json`, and the U0 note says to add it to `POLLED_COMMANDS` only if the UI polls it — it does not).
- The release page is the fixed `releases/latest` URL, copied as text (no opener capability in the main window, same as About U3). An `open_url` command would make it one click.
