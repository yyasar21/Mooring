## Done

1. **Every import refusal is audited** (`47cc875`, Q1 decision 1). `commands/import.rs::preview`
   now runs read → detect → parse in `read_and_parse` and audits any `import.*`-coded error
   from it as `import_refused { code }`: undetected format (`import.format`), unreadable or
   oversized source (`import.not_found`, `import.too_large`), every parser code. `input.invalid`
   (malformed request, used pick) stays unaudited: it is not a refusal of a file.
   `a4_import::undetected_format_is_audited_as_a_refusal` un-ignored (+ only-a-code and marker
   checks); new unit test `read_stage_refusals_are_audited_and_malformed_requests_are_not`.
2. **`rdp_reactivation` fuzz target** (`c521080`, review 5 L-28 remainder, Q1 decision 2).
   `mooring_proto_rdp::fuzz::reactivation(data)` (+ `reactivation_outcome` → `Option<(w, h)>`
   for the seed test): each `[len16, bytes]` frame is one hostile server PDU stepped through a
   fresh `ConnectionActivationSequence` built from the product connector config (ids 1002 /
   1003 like the other RDP entries), with `step_no_input` on the client's own turns exactly as
   `single_sequence_step_read` does; a finalized sequence goes through `check_desktop` and
   `ActiveStage::reactivate` like `active::reactivate` after a `DeactivateAll`. Seeds (encoded
   with the IronRDP encoders, committed as bytes): `demand-active-finalized` (1024×768),
   `deactivate-then-demand` (leading `DeactivateAll`, 1280×800), `oversize-desktop`
   (60000×60000 → refused by `check_desktop`), `truncated`, `error-info`.
   `tests/fuzz_corpus.rs`: replay + `rdp_reactivation_seeds_reach_the_reactivation_branch`
   (the two full sequences finalize, the three others do not). Proptest `never_panic` covers
   the entry too. `cd fuzz && cargo check --bins --offline` → 55 bins.
3. **`mooring-audit/src/event.rs` split** (`9a5f5fa`). 766 lines →
   `event/{mod,vault,sessions,web,kube,vsphere,secrets,sync,a4}.rs` (50–179 lines each). One
   `pub enum AuditEvent` still: each phase file holds a `<phase>_variants!` macro that appends
   its variants to a chain (`[next, …] acc…`) ending in `define_audit_event!`, which emits the
   enum with the unchanged `#[serde(tag = "event", rename_all = "snake_case")]` and every
   per-variant `rename` / `default` / `skip_serializing_if` as before. Variant order changed
   (grouped by phase), which serde does not observe; `cargo test -p mooring-audit` 36/36 and the
   app's audit assertions (`e2e_flow` 39, lib 331) are unchanged. `mod core` was avoided
   (`core::` ambiguity with the extern prelude) — the vault/credential/trust group is `vault.rs`.
4. **`ldap_bind` by what the server saw** (`022b274`, Q1 observation b).
   `mooring_import::ldap` gains `BindSignal` (shared `AtomicU8`) / `BindPhase`
   (`NotAttempted | Attempted | Bound`), set by `DirectoryReader::connect` just before the bind
   request goes out and after `rc == 0`; `preview`, `fetch`, `bind_only` take `&BindSignal`.
   `commands/ldap_import.rs::with_trust` audits: `Ok` or `Bound` → `ldap_bind { success: true }`
   (so a run that dies on a hostile frame after the bind reads bind → `import_refused`),
   `Attempted` → `success: false` (refused bind, hostile bind reply, dropped connection or
   deadline during the bind — not only `LdapError::Bind` as before), `NotAttempted` → nothing
   (trust refusal, missing prompt, TLS or connect failure: `cert_decision` or the code only,
   as the Q1 tests pin). New unit test `bind_rows_bracket_a_run_that_dies_after_the_bind`;
   `a4_ldap::hostile_server_frames…` now expects `cases.len() + 2` bind rows, all `true`.
5. **`update.install_failed` message is static** (`9352dbe`). By construction already:
   `SourceError` is fieldless, `message()` is a fixed sentence per class, the `IpcError` is
   built from it, and the plugin's text (URLs, bundle paths) goes to `tracing::warn!` only.
   `updater::tests::source_errors_map_to_codes` now asserts no `/`, `\`, `://`, `..`, `%` in
   any message; `update_tests::install_rechecks…` asserts `e.message == err.message()` for
   `update.signature` and `update.install_failed`.
