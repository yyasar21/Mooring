## Left open
- **`credential.external_*` are not in `src-tauri/ipc-codes.json`** (the list is generated from src-tauri's own constructors; E1's `SecretsError::code()` values are missing). They stay in `PENDING_A3_CODES` with that note, so the "A3 codes are Rust codes" check is the one skipped test. rust-core: add them to the generator or the list.
- **No global alarm banner.** The fork/rollback banner lives on the Vault sync card only; the shell does not surface it elsewhere (Shell.tsx is U2 territory this round).
- **Connect-time resolution is not mocked.** `session_open` with an `external_ref` credential succeeds in the mock as if the target credential were stored; the `credential.external_*` friendly texts are reachable only from Rust. The friendly map is tested through `describeCode`.
- **Source trust prompt**: E2 has no `secret_source_trust` yet; an unknown self-signed Vault certificate shows as a failed test with category `tls` and the CA PEM option is the way out.
- **OIDC window closed by the user**: the UI only learns it from the poll (`closed`); there is no "Cancel" button that closes the window from the UI (no command for it).
- **Join password**: the bootstrap vault is created with the synced vault's password (so a failed join leaves a vault the user can unlock). If the typed password is wrong, `vault_join` fails with `vault.unlock` and the retry re-creates nothing; the bootstrap stays unlocked until the join succeeds or the app restarts.
- Bundle: the main chunk is still over Vite's 500 kB warning (MockTransport ships in it, as before).
